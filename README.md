# noise-level-detector
This project is a prototype of a noise level detector, using an IR sensor, analog output microphone, servo motor, and microcontroller to notify a user if they are too loud in a designated quiet area. 

The main objective of this project is to design a prototype of a noise detector to be used in these designated quiet study areas. This detector system works by using an IR sensor to detect if a person is sitting at a desk (which turns the whole system on). If a person is in a quiet area and starts talking, they receive a warning light. If they make noise for over a predetermined time, they are issued a warning, and a sign saying "Quiet Please" appears.
